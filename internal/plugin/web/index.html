查看审核输入与 JSON 返回要求

用户文本通过独立 user 消息中的 user_messages 数组传入，应作为待审数据处理。两种模式均须返回下列四个字段。 

{"is_violation": true, "confidence": 92, "categories": ["cybersecurity"], "reason": "Brief classification reason in English."}

confidence 为 0–100 的数字；categories 仅允许 cybersecurity、political、nsfw。违规时至少一个类别，未违规时为空数组。reason 为不超过 400 字符的简短英文理由。
